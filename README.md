# メンテナンス管理ポータル（Vue モック）

## 起動方法
Node.js 20 以降を用意し、このフォルダで以下を実行してください。

```bash
npm install
npm run dev
```

表示された `http://localhost:5173/` をブラウザで開きます。

## 共有方法
- 同じネットワーク内で見せる場合：起動時のPCのIPアドレスとポート5173を相手に伝えてください（ファイアウォール設定が必要な場合があります）。
- 別の場所の人に見せる場合：GitHub等に配置してAzure Static Web Appsなどへデプロイするか、社内で利用可能なホスティング環境に配置してください。

## モックの範囲
- 店舗スタッフ画面：ダッシュボード、顧客・機材、定期メンテナンス、イベント前点検、メール管理
- 顧客画面：左下の「表示モード」から顧客マイページへ切替
- 定期点検を「実施完了」にすると、サンプルデータ上の契約残回数が1回減ります
- イベント前点検は定期契約の残回数に影響しません
- メール送信はデモ表示のみで、実際のメールは送信されません
- データはブラウザ内のメモリ上のみで、再読み込みすると初期状態に戻ります
- 認証、DB、API、実際のメール送信、登録画面は未実装です
