# ROAD BIKE CARE - メンテナンス管理モック

Vue 3 + TypeScript + Vite による画面モックです。

## 今回の更新
- 年間契約登録画面を追加（12月1日開始、翌年11月30日終了）
- 契約登録時に顧客・自転車・プラン・担当店舗・受付担当者を関連付け
- メンテナンス／点検／オーバーホールの未完了予定を編集可能
- 店舗情報と店舗ごとの受付担当者の登録・一覧画面を追加
- 予定変更では契約回数を消費せず、作業完了時のみ消費

## 起動
```bash
npm install
npm run dev
```

## ビルド
```bash
npm run build
```

## 注意
このモックのデータは Vue のメモリ上に保持され、ブラウザ再読み込みで初期化されます。認証、API、データベース、実メール送信は未実装です。店舗・担当者・契約・予定の関連付けは画面動作確認用です。実運用では店舗ID・スタッフID・契約IDを外部キーとしてAPI/DBで管理してください。
