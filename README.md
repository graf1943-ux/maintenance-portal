# Road Bike Care - メンテナンス管理モック

ロードバイクのオーバーホール、2か月単位の定期メンテナンス、イベント前点検を管理するVueモックです。

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:5173/` を開いてください。

## モックに含まれる画面

- ダッシュボード：直近のオーバーホール・定期点検予定、イベント前点検、契約プラン
- 顧客・自転車管理：顧客ごとのロードバイク、メーカー・モデル、製造番号、契約プラン
- オーバーホール管理：指定日・実施完了の管理
- 定期メンテナンス：オーバーホール完了日を起点とする2か月ごとの予定
- イベント前点検：イベントごとの点検予定・完了管理
- メンテナンス履歴：自転車単位の作業履歴
- 連絡・メール管理：案内メールのプレビュー（実送信なし）
- 顧客マイページ：契約中の自転車と点検予定

## デモ操作

1. 「オーバーホール管理」を開き、未完了のオーバーホールで「実施完了」を押します。
2. オーバーホールの実施完了日から2か月ごとの定期メンテナンス予定が、契約回数分作成されます。
3. 「定期メンテナンス」で「実施完了」を押すと、定期メンテナンスの残回数が1回減り、履歴に追加されます。
4. 「イベント前点検」で「点検完了」を押しても、定期メンテナンスの残回数は変わりません。

## 予定日の計算ルール

オーバーホール実施完了日を基準に、2か月、4か月、6か月後…の日付を作成します。対象月に同じ日付が存在しない場合は月末日に補正します（例：12月31日の2か月後は2月末日）。

## 注意事項

- このモックはサンプルデータをブラウザ上で操作するデモです。データベースへの保存は行わず、再読み込みすると初期状態に戻ります。
- メールはプレビューのみで、実際には送信されません。
- 新規登録・編集フォーム、ログイン、API、DB連携、実際の契約・請求処理は未実装です。
- サンプルのプラン名・契約回数・顧客名・自転車情報・日付は仮データです。
