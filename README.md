# ROAD BIKE CARE - メンテナンス管理モック

Vue 3 + TypeScript + Vite による画面モックです。

## 今回の更新
- 年間契約登録画面を追加（12月1日開始、翌年11月30日終了）
- 契約登録時に顧客・自転車・プラン・担当店舗・受付担当者を関連付け
- メンテナンス／点検／オーバーホールの未完了予定を編集可能
- 店舗情報と店舗ごとの受付担当者の登録・一覧画面を追加
- 予定変更では契約回数を消費せず、作業完了時のみ消費

## 起動
```bash
npm install
npm run dev
```

## ビルド
```bash
npm run build
```

## 注意
このモックのデータは Vue のメモリ上に保持され、ブラウザ再読み込みで初期化されます。認証、API、データベース、実メール送信は未実装です。店舗・担当者・契約・予定の関連付けは画面動作確認用です。実運用では店舗ID・スタッフID・契約IDを外部キーとしてAPI/DBで管理してください。


## 一覧検索

一覧画面にはキーワード検索を追加しています。顧客名、自転車名・モデル、プラン、店舗、担当者、予定名、作業内容、日付、状態など、画面ごとに関連する項目を横断して絞り込めます。検索欄を空にすると全件表示に戻ります。

## デモデータ（複数台契約）
- 山田 太郎様が「SPECIALIZED Tarmac SL8 Expert」と「CANYON Speedmax CF 7」の2台を契約しているサンプルデータを登録しています。
- 顧客・自転車一覧では同じ顧客名に「2台契約」と表示し、自転車ごとに別のプラン・契約回数・作業予定・履歴を管理します。
- 顧客マイページでは山田 太郎様の2台分の契約と予定を確認できます。
